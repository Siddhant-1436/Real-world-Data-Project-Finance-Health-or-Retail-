# Patient Diabetes Risk Prediction

An end-to-end data science project applying exploratory analysis and
machine learning to a patient records dataset, predicting diabetes risk
from clinical and lifestyle features.

## Overview

- **Domain:** Health / clinical data
- **Task:** Binary classification (diabetes risk prediction)
- **Data:** 2,000 synthetic patient records (see [Dataset](#dataset))
- **Models:** Logistic Regression, Random Forest
- **Best result:** ROC-AUC 0.847 (Logistic Regression)

Full write-up with charts and conclusions: [`reports/Patient_Diabetes_Risk_Report.docx`](reports/Patient_Diabetes_Risk_Report.docx)

## Dataset

The dataset (`data/patient_records.csv`) is **synthetically generated**
for learning purposes — it is not real patient data. It includes 12
features per patient (age, sex, BMI, blood pressure, cholesterol,
glucose, smoking status, family history, physical activity, alcohol use,
sleep hours) plus a binary `diabetes` outcome label, with realistic
correlations between risk factors and target, class imbalance (~20%
positive), and missing values in a few columns to mimic real clinical
data quality issues.

## Usage

Run the scripts in order from the repo root:

```bash
python src/01_generate_data.py   # regenerates data/patient_records.csv
python src/02_eda.py             # writes EDA charts to charts/
python src/03_modeling.py        # trains models, writes results to charts/ + reports/
```

## Results

| Model               | Accuracy | ROC-AUC | F1-score |
|---------------------|----------|---------|----------|
| Logistic Regression | 75.2%    | 0.847   | 0.547    |
| Random Forest       | 79.0%    | 0.819   | 0.571    |

**Top predictors of diabetes risk:** glucose level, age, BMI, cholesterol,
systolic blood pressure.

See the [full report](reports/Patient_Diabetes_Risk_Report.docx) for
detailed EDA, charts, and conclusions.
